# Журнал решений по разбору диалогов

Сюда агент разбора (см. `.claude/skills/dialog-review/SKILL.md`)
записывает, что владелец принял и что отклонил, чтобы не предлагать
одно и то же повторно. Без имён, телефонов и id диалогов. Можно
править руками на GitHub.

## Уже решено до запуска разбора (из истории правок, сентябрь 2026)

- Бот не называет себя человеческим именем, сразу говорит, что он ИИ.
- Язык: по умолчанию русский; на кыргызский переходит, если клиент сам
  пишет на кыргызском (даже коротко). Пересланные посты/ссылки не
  переключают язык.
- Двусмысленное сообщение — уточнить, не отвечать наугад; неясно и
  после уточнения — передать менеджеру.
- Гайд по ДДУ ботом автоматически не рассылается — только приглашение
  в офис продаж; сигнал «+» из рекламы = запрос гайда → кратко о гайде
  и приглашение в офис.
- Вернувшийся после паузы клиент — тёплое приветствие и передача
  менеджеру, без повторной квалификации.
