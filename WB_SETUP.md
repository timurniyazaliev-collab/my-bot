# Настройка синхронизации Wildberries → Google Таблицы

Это разовая настройка. Код уже в репозитории и подтянется на сервер сам
(автодеплой), но секретные ключи через GitHub не передаются специально —
их нужно один раз положить на сервер руками. Дальше всё будет работать
само: бот сам, каждые несколько часов, забирает из WB продажи, заказы,
остатки и финансовый отчёт и дописывает их в твою Google Таблицу.

## Шаг 1. Токен Wildberries

1. Зайди в личный кабинет продавца WB → раздел «Настройки» → «Доступ к
   API».
2. Создай новый токен. Категории доступа отметь минимум: «Статистика» и
   «Финансовые отчеты» (только на чтение, писать в WB бот пока не
   умеет).
3. Скопируй токен — он показывается один раз.

## Шаг 2. Доступ к Google Таблицам (сервисный аккаунт)

Боту нужен отдельный «служебный» Google-аккаунт, которому ты дашь
доступ к своей таблице (без пароля от твоей личной почты).

1. Зайди на https://console.cloud.google.com/ (можно через обычный
   Google-аккаунт).
2. Создай новый проект (кнопка сверху «Select a project» → «New
   project»), назови как угодно, например `wb-bot`.
3. В поиске сверху введи «Google Sheets API» → открой → нажми
   «Enable» (включить).
4. Слева в меню: «IAM & Admin» → «Service Accounts» → «Create service
   account». Имя любое, например `wb-sheets-bot`. Роль можно не
   назначать, жми «Done».
5. Открой созданный сервисный аккаунт → вкладка «Keys» → «Add key» →
   «Create new key» → тип JSON → скачается файл.
6. Переименуй скачанный файл в `google_service_account.json`.
7. Открой этот файл текстовым редактором, найди строку `"client_email"`
   — это email вида `wb-sheets-bot@wb-bot-123456.iam.gserviceaccount.com`.
8. Открой свою Google Таблицу → кнопка «Настройки доступа» / «Share» →
   вставь этот email → дай права «Редактор» (Editor).
9. Скопируй ID таблицы — это часть ссылки между `/d/` и `/edit`:
   `https://docs.google.com/spreadsheets/d/ЭТОТ_ID/edit`.

## Шаг 3. Разово положить секреты на сервер

Через SSH (единственный раз, дальше руками сервер не трогаем):

```
scp google_service_account.json root@<адрес_сервера>:/root/my-bot/
ssh root@<адрес_сервера>
nano /root/my-bot/.env
```

Добавь в `.env` три строки (без кавычек):

```
WB_API_TOKEN=токен_из_шага_1
GOOGLE_SHEET_ID=id_таблицы_из_шага_2
GOOGLE_SERVICE_ACCOUNT_FILE=/root/my-bot/google_service_account.json
```

Необязательно, есть значения по умолчанию:

```
WB_SYNC_DAYS=30            # за сколько дней назад забирать данные каждый раз
WB_SYNC_INTERVAL_HOURS=3   # как часто синхронизировать автоматически
```

Сохрани файл (в nano: Ctrl+O, Enter, Ctrl+X) и перезапусти бота:

```
systemctl restart mybot
```

## Шаг 4. Проверка

В Telegram напиши боту `/wb_sync` — он сходит в WB и запишет данные в
таблицу (создаст вкладки «Продажи», «Заказы», «Остатки», «Финансы»,
если их ещё нет), и пришлёт отчёт, сколько строк добавил.

Дальше синхронизация идёт сама каждые `WB_SYNC_INTERVAL_HOURS` часов, а
`/wb_sync` можно вызывать вручную в любой момент.
