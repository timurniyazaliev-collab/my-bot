# MadeInside — автоматизация YouTube-канала

Ниша: process-контент "как это сделано" (гитары, стекло, кроссовки,
шоколад, мебель). Формат: faceless, английский язык, бесплатные/лицензионные
архивные кадры + оригинальный сценарий и озвучка.

Полностью независимый модуль — не связан ни с Telegram-ботом (`bot.py`,
`sales_ai.py`), ни с `viral_platform/`. Свой `.env`, свой
`requirements.txt`, не участвует в автодеплое бота.

## Как это устроено

Десять шагов, каждый — отдельный скрипт, можно запускать и по одному, и
через оркестратор:

| Шаг | Скрипт | Что делает |
|---|---|---|
| 1 | `01_ideas.py` | Генерирует темы роликов (Claude), пишет в `ideas_backlog.json` |
| 2 | `02_script.py` | Сценарий по одной идее: 6-7 блоков, таймкоды считаются по числу слов |
| 3 | `03_shotlist.py` | Поисковые запросы для стокового видео по каждому блоку |
| 4 | `04_fetch_footage.py` | Скачивает клипы с Pexels, логирует источник/лицензию |
| 5 | `05_tts.py` | Озвучка по блокам (ElevenLabs или Google Cloud TTS) |
| 6 | `06_assemble.py` | Монтаж: footage под длину озвучки, музыка, нормализация громкости, субтитры |
| 7 | `07_thumbnail.py` | 2-3 варианта превью (кадр из видео + текст) |
| 8 | `08_metadata.py` | Заголовок, описание с таймкодами, теги |
| 9 | `09_review.py` | **Ручная проверка** — approve / reject / redo-step-N |
| 10 | `10_publish.py` | Загрузка на YouTube по расписанию (OAuth) |

`run_pipeline.py` прогоняет 1-8 автоматически, останавливается на 9
(проверке) и запускает 10 только после `approve`.

Шаг 9 намеренно не автоматизирован: YouTube занижает охват однотипного
ИИ-контента без правок человека, и это единственная точка, где можно
поймать плохой сценарий или кадр не в тему до публикации.

## Что нужно завести заранее

1. **Anthropic API key** (console.anthropic.com) — шаги 1, 2, 3, 8.
2. **Pexels API key** (pexels.com/api, бесплатно) — шаг 4.
   Videvo туда же не входит: у него нет стабильного публичного API для
   скачивания по запросу, только шаг 4 предупредит и напомнит докачать
   клипы оттуда вручную в `assets/<id>/raw/`.
3. **ElevenLabs API key** (elevenlabs.io, есть бесплатный тариф) — шаг 5.
   Либо `TTS_PROVIDER=google` + сервис-аккаунт Google Cloud — дешевле,
   но качество голоса ниже.
4. **Google Cloud проект** с включённым YouTube Data API v3 + OAuth-клиент
   (тип Desktop app, `client_secret.json` в `madeinside/`) — шаг 10.
5. **ffmpeg** в системе: `apt install ffmpeg` / `brew install ffmpeg`.

Про генерацию превью (шаг 7): в списке ключей выше нет API для генерации
картинок (DALL-E/Stability/Imagen и т.п.), поэтому превью собираются иначе
— берётся кадр из уже скачанного footage и накладывается жирный текст
(через Pillow). Это рабочий и распространённый способ делать превью для
faceless-каналов, но если хочется именно генеративную картинку — это
отдельная интеграция, скажите, добавим.

## Установка

```bash
pip install -r madeinside/requirements.txt
cp madeinside/.env.example madeinside/.env
# откройте madeinside/.env и вставьте ключи
```

Запускать скрипты нужно из папки `madeinside/` (или указывая путь —
главное, чтобы `config.py`/`common.py` лежали рядом):

```bash
cd madeinside
python 01_ideas.py --count 10
```

## Типичный прогон

```bash
python run_pipeline.py                 # сгенерирует идеи, спросит какую делать,
                                        # прогонит шаги 2-8, откроет видео на проверку
# после approve — сразу публикует по расписанию из schedule.json
```

Или по идее, которая уже есть в backlog:

```bash
python run_pipeline.py --idea-id guitar-body-sanding-7f3a2c
```

После `redo-step-N` на проверке — доработайте и продолжите с этого шага:

```bash
python run_pipeline.py --idea-id <id> --from-step 5
```

## Файлы и папки

```
madeinside/
  ideas_backlog.json          — идеи + статус (backlog/scripted/approved/scheduled/...)
  scripts/<id>.json           — сценарий с таймкодами
  scripts/<id>.shotlist.json  — поисковые запросы по блокам
  assets/<id>/raw/            — скачанное footage
  assets/<id>/audio/          — озвучка по блокам
  assets/<id>/sources.txt     — источники и лицензии footage
  assets/<id>/thumbnail_N.jpg — варианты превью
  render/<id>.mp4             — готовое видео
  render/<id>.srt             — субтитры
  metadata/<id>.json          — заголовок/описание/теги
  schedule.json                — расписание публикаций (дни недели + время + часовой пояс)
  client_secret.json, token.json — YouTube OAuth (не коммитятся)
```

Всё, что генерируется пайплайном (backlog, сценарии, footage, аудио,
рендеры, метаданные, OAuth-токены) — в `.gitignore`, в репозитории лежит
только код и `schedule.json`.

## Известные ограничения v1

- Кроссфейды между кадрами (`--crossfade` у `06_assemble.py`) реализованы,
  но менее обкатаны, чем жёсткая склейка по умолчанию — проверьте на
  одном видео перед тем, как полагаться на них в проде.
- Videvo — только ручная докачка (см. выше).
- Превью — кадр + текст через Pillow, не генеративная картинка.
