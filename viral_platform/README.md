# Виральные Shorts — поиск идей для коротких видео

Отдельный инструмент внутри этого репозитория. **Никак не связан** с
Telegram-ботом (`bot.py`, `sales_ai.py`) — не мешает ему и не входит в его
деплой. Это веб-дашборд (открывается в браузере), а не бот.

## Что умеет сейчас (этап 1)

1. Ищет реально вирусные YouTube Shorts через официальный YouTube Data
   API — по ключевому слову/нише и за последние N дней. Сортирует не по
   общим просмотрам, а по "просмотров в день" — так свежие набирающие
   обороты ролики не теряются среди старых с миллионами просмотров.
2. Открываете ролик — можно посмотреть его прямо на странице.
3. "Транскрибировать" — скачивает звук и превращает в текст (локально,
   без платных API, через faster-whisper).
4. "Построить раскадровку" — Claude разбирает транскрипт по сценам
   (хук, проблема, решение, доказательство, призыв к действию) и
   объясняет, почему цепляют первые секунды.
5. "Сгенерировать сценарий" — пишет НОВЫЙ сценарий под вашу нишу
   (описана в `niche.md`), используя структуру и приём чужого ролика,
   но не копируя его слова и факты.

## Что будет дальше (не реализовано)

- Автопубликация готовых видео в свои каналы (YouTube/Instagram/TikTok).
- Полностью автоматическая моушн-графика (сборка видео из сценария —
  титры, анимация, монтаж) для вертикального и горизонтального формата.

Это отдельные большие этапы, будем делать по очереди.

## Как запустить

Нужны два ключа:

- **YouTube API key** — бесплатно. Google Cloud Console → создать проект
  → включить "YouTube Data API v3" → Credentials → Create API key.
- **Anthropic API key** — тот же, что используется в Telegram-боте
  (можно взять из его `.env`, либо создать отдельный на
  console.anthropic.com).

Установка (из корня репозитория `my-bot`):

```bash
pip install -r viral_platform/requirements.txt
```

Также нужен `ffmpeg` в системе (для извлечения звука из видео):

```bash
# Ubuntu/Debian:
apt-get install -y ffmpeg
# macOS:
brew install ffmpeg
```

Настройка ключей:

```bash
cp viral_platform/.env.example viral_platform/.env
# откройте viral_platform/.env и вставьте ключи
```

Запуск дашборда:

```bash
python -m uvicorn viral_platform.main:app --reload --port 8001
```

Открыть в браузере: http://localhost:8001

## Свой сценарий под свою нишу

Отредактируйте `viral_platform/niche.md` (прямо на GitHub) — опишите,
о чём должны быть ваши ролики. Этот текст автоматически попадает в
промпт при генерации сценария (можно и переопределить прямо в форме на
странице видео).

## Деплой на сервер (когда понадобится)

Пока не подключено к автодеплою бота — работает только вручную/локально.
Когда будет готово выкатывать на VPS, сделаем отдельным systemd-сервисом
(например `viral-platform.service`) на отдельном порту — без изменений
в `mybot.service`.
