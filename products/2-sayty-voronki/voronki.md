# Продукт 2. Шаблоны сайтов и воронок — состав

Формат: готовые HTML-файлы (открываются в браузере, загружаются на любой хостинг или в Tilda через HTML-блок) + схема воронки + тексты сообщений. К каждому шаблону — инструкция «что поменять за 30 минут».

## Шаблоны сайтов
| № | Шаблон | Для кого | Статус |
|---|---|---|---|
| 1 | Лендинг услуг (`landing-uslugi.html`) | ремонт, салон, агентство, клининг, юристы | ✅ готов |
| 2 | Лендинг товара / мини-магазин | продавцы 1–10 товаров, Instagram-магазины | план |
| 3 | Сайт-визитка специалиста | психолог, тренер, репетитор, фотограф | план |
| 4 | Лендинг мероприятия / вебинара | эксперты, курсы, события | план |
| 5 | Страница лид-магнита (гайд / чек-лист за контакт) | любой бизнес с рекламой | план |
| 6 | Лендинг объекта недвижимости | застройщики, риэлторы | план |

## Шаблоны воронок (схема + тексты)

### Воронка 1. «Реклама → лид-магнит → Telegram-бот → продажа»
1. Реклама в Instagram / YouTube Shorts: «Забери бесплатно [чек-лист]».
2. Страница лид-магнита или сразу Telegram-бот (кнопка «Получить»).
3. Бот выдаёт лид-магнит и задаёт 1 вопрос для сегментации.
4. Дожимающая цепочка (тексты в шаблоне):
   - День 0: лид-магнит + короткая история + мягкое предложение.
   - День 1: частая ошибка + как её решает продукт.
   - День 3: отзыв / кейс + скидка на 48 часов.
   - День 5: последнее напоминание о скидке.
5. Оплата по ссылке → автоматическая выдача продукта → просьба оставить отзыв через 3 дня.

### Воронка 2. «Реклама → лендинг → заявка → менеджер»
Для услуг с чеком выше среднего: лендинг (шаблон 1) → форма → уведомление менеджеру в Telegram → звонок за 15 минут (→ **Регламент обработки заявки**).

### Воронка 3. «Трипваер»
Недорогой продукт за 3–5 $ → после покупки предложение пакета со скидкой на странице «Спасибо» → через 7 дней — более дорогой пакет.

### Воронка 4. «Возврат клиента»
База клиентов → раз в месяц полезное сообщение + персональное предложение → отзыв → «приведи друга».
