# Магазин бизнес-шаблонов — каталог и статус

Временная папка внутри репозитория бота (на ветке, не в main): отдельный
репозиторий создать не получилось из-за прав доступа. Когда создашь
приватный репозиторий `digital-products` на GitHub, перенесу сюда.

Путь клиента, сайт и доверие — `put-klienta.html`.
Общий план и бюджет — `AUTONOMY-PASSPORT.html` (направление 2).

Рынок: Бишкек → Ош → крупные города КР. Аудитория: начинающие
предприниматели, продавцы, малый бизнес, фрилансеры.
Оплата: интернет-эквайринг Mbank (Visa, Mastercard, Apple Pay).
