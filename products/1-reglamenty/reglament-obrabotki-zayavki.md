# Регламент обработки входящей заявки

**Для кого:** любой бизнес, который получает заявки из Instagram, WhatsApp, Telegram, с сайта или по телефону: услуги, магазин, салон, агентство, застройщик.
**Зачем:** ни одна заявка не теряется, клиент получает ответ быстро, менеджер знает, что делать на каждом шаге.
**Как пользоваться:** замени значения в [квадратных скобках] под свой бизнес, распечатай или закрепи в рабочем чате, ознакомь сотрудников под подпись.

---

## 1. Общие правила

| Правило | Значение для вашего бизнеса |
|---|---|
| Время первого ответа в рабочие часы | не более [15] минут |
| Время первого ответа в нерабочие часы | до [10:00] следующего рабочего дня + автоответ |
| Рабочие часы | [пн–сб, 9:00–19:00] |
| Где фиксируется каждая заявка | [CRM / Google-таблица «Заявки» / Notion] |
| Ответственный за распределение заявок | [должность / имя] |

**Золотое правило:** заявка, которой нет в [CRM / таблице], считается потерянной.

## 2. Этапы

### Этап 1. Приём (0–15 минут)
1. Поприветствовать, представиться, назвать компанию.
2. Поблагодарить за обращение.
3. Внести заявку в [CRM / таблицу]: дата, канал, имя, контакт, что интересует.
4. Задать **один** уточняющий вопрос, чтобы продолжить диалог.

> Пример: «Здравствуйте, [имя]! Меня зовут [имя], компания [название]. Спасибо, что написали. Подскажите, для каких целей рассматриваете [товар / услугу]?»

### Этап 2. Квалификация (в первом диалоге)
Выяснить (не допрашивать — по одному вопросу, чередуя с полезной информацией):
- ☐ Потребность: что именно нужно и для чего
- ☐ Сроки: когда нужно
- ☐ Бюджет: ориентир по сумме
- ☐ Кто принимает решение
- ☐ Что уже смотрели / с чем сравнивают

Статус в CRM: **Новый → Квалифицирован** или **Не целевой** (с причиной).

### Этап 3. Предложение
1. Подобрать 1–3 варианта под ответы клиента, не больше.
2. Отправить КП / прайс / фото / презентацию [шаблон: ссылка].
3. Предложить следующий шаг: встречу, звонок, замер, пробный заказ.
4. Договориться о конкретной дате и времени следующего контакта.

### Этап 4. Работа с возражениями
| Возражение | Как отвечаем |
|---|---|
| «Дорого» | Уточнить, с чем сравнивает → показать, что входит в цену → предложить вариант дешевле или рассрочку |
| «Подумаю» | «Конечно. Что для вас важно взвесить — цену, сроки, условия?» → договориться о дате связи |
| «Нашёл дешевле» | Сравнить по составу услуги, гарантиям, срокам — без критики конкурента |
| [ваше частое возражение] | [ваш ответ] |

### Этап 5. Закрытие
1. Подтвердить заказ письменно: что, сколько, когда, стоимость.
2. Отправить договор / счёт / ссылку на оплату.
3. Статус в CRM: **Оплачено** / **Договор подписан**.
4. Передать заказ в исполнение: [кому, как].

### Этап 6. Если клиент пропал
| Когда | Что делаем |
|---|---|
| Через 24 часа | Короткое сообщение с пользой: ответ на его вопрос, фото, кейс |
| Через 3 дня | Звонок или голосовое сообщение |
| Через 7 дней | Последнее касание: «Актуально ли ещё?» → статус **Отложен** с датой возврата |
| Через [30] дней | Возврат с новым предложением / акцией |

## 3. Чего не делаем
- Не оставляем сообщение без ответа, даже если ответ — «уточню и вернусь до [времени]».
- Не отправляем прайс без вопроса и без приглашения к следующему шагу.
- Не обещаем того, что не можем гарантировать (сроки, скидки без согласования).
- Не спорим с клиентом и не критикуем конкурентов.

## 4. Контроль
- Руководитель ежедневно в [18:00] проверяет: все ли заявки за день внесены и у всех ли есть следующий шаг с датой.
- Еженедельно: конверсия «заявка → оплата» по каждому менеджеру и каналу.
