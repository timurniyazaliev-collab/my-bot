# Продукт 3. Шаблоны и системы для Notion — структура

Как продаётся: покупатель получает ссылку «Duplicate» (копировать шаблон к себе в Notion) и видеоинструкцию на 3–5 минут. Шаблоны собираются в отдельном Notion-аккаунте магазина и публикуются как шаблоны (Share → Publish → Allow duplicate as template).

Статус: структура готова. Сами страницы в Notion соберу после твоего «да»: создать их можно в твоём Notion через подключённый коннектор, отдельной папкой «Магазин шаблонов».

---

## 3.1. CRM для малого бизнеса ★ (старт)

**Для кого:** салоны, агентства, фрилансеры, небольшие магазины, риэлторы.

| База | Поля |
|---|---|
| **Клиенты** | Имя, телефон, канал (Instagram / WhatsApp / Telegram / сайт / рекомендация), статус, ответственный, дата следующего контакта, сумма покупок (rollup), заметки |
| **Сделки** | Клиент (relation), продукт, сумма, этап (Новая → Квалифицирована → КП отправлено → Переговоры → Оплачено / Отказ), причина отказа, дата закрытия |
| **Касания** | Клиент, дата, тип (звонок / сообщение / встреча), итог, следующий шаг |
| **Продукты / услуги** | Название, цена, себестоимость, маржа (formula) |

**Виды:** канбан сделок по этапам · «Позвонить сегодня» (фильтр по дате контакта) · «Горячие» · дашборд: сумма сделок в работе, оплачено за месяц, конверсия по каналам.
**Шаблоны страниц:** карточка клиента с чек-листом квалификации, скрипт первого звонка.

## 3.2. Система задач и проектов для команды ★

| База | Поля |
|---|---|
| **Проекты** | Название, цель, статус, срок, ответственный, прогресс (rollup % выполненных задач) |
| **Задачи** | Проект, исполнитель, приоритет, срок, статус, повторяемость, чек-лист |
| **Встречи** | Дата, участники, повестка, решения, задачи (relation) |

**Виды:** «Мои задачи сегодня» · канбан · календарь сроков · просроченные.
**Шаблоны:** еженедельная планёрка, разбор проекта, передача дел сотруднику.

## 3.3. Контент-план для SMM ★

| База | Поля |
|---|---|
| **Публикации** | Тема, формат (пост / reels / сторис / shorts), площадка, дата, статус (Идея → Сценарий → Съёмка → Монтаж → Опубликовано), рубрика, ссылка, охват, заявки |
| **Идеи** | Идея, источник, рубрика, в работу (checkbox) |
| **Рубрикатор** | Рубрика, цель, доля в контенте |

**Виды:** календарь публикаций · канбан производства · статистика по рубрикам.
**Шаблоны:** сценарий reels по кадрам, бриф для дизайнера.

## 3.4. Личная система «Второй мозг / Life OS»

Инбокс, сферы жизни, цели на квартал, привычки, еженедельный обзор с чек-листом, финансы (доходы и расходы по категориям).

## 3.5. База знаний и онбординг сотрудников

Регламенты (из продукта 1), должностные инструкции, FAQ, «Первая неделя нового сотрудника» с чек-листом, тесты после обучения.

## 3.6. Учёт для продавца маркетплейса (Notion-версия)

Товары, поставки, остатки, продажи по неделям, задачи по карточкам (фото, SEO, отзывы).
