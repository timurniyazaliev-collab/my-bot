# Ежедневный разбор диалогов — как включить

Что это и зачем — `AUTONOMY-PASSPORT.html`. Как агент работает —
`.claude/skills/dialog-review/SKILL.md`. Здесь только разовая настройка.
Ключи никогда не присылай в чат — только в поля настроек.

## 1. Сервер (один раз)

1. Сгенерировать отдельный ключ для агента разбора:
   `python3 -c "import secrets; print(secrets.token_urlsafe(32))"`
2. Добавить в `.env` на сервере строку `REVIEW_API_KEY=<ключ>`.
3. Перезапустить сервис вебхука (`mybot-webhook.service` или как он
   назван) и сервис бота. ВАЖНО: проверить, перезапускает ли
   автодеплой сервис вебхука — если только `mybot.service`, изменения
   в `webhook_server.py` без ручного перезапуска не заработают.

Этот ключ открывает только `/api/review/dialogs` (чтение диалогов, без
телефонов/id) и `/api/review/message` (сообщение владельцу в Telegram).
Писать клиентам, сбрасывать или менять историю им нельзя.

## 2. Облачное окружение Claude (claude.ai/code → окружение → Edit)

1. Network access → Custom: добавить адрес вебхука (тот же домен, что
   отдали CRM), оставить галочку со стандартным списком.
2. API credentials → Add credential: Allowed websites — домен вебхука;
   Custom headers — имя `X-API-Key`, префикс пустой, значение — ключ из
   шага 1.1. Агент ключ не видит, прокси подставляет его сам.
3. Environment variables: `REVIEW_BASE_URL=https://<домен вебхука>`
   (это не секрет).

## 3. Два Routine (claude.ai/code/routines)

- «Разбор диалогов»: репозиторий my-bot, окружение из шага 2, ежедневно
  в 8:43 по Бишкеку. Коннекторы — никакие не нужны. Промпт:
  «Прочитай .claude/skills/dialog-review/SKILL.md и выполни режим 1
  (разбор) за вчерашний день.»
- «Применить ответ»: то же, без расписания, только API-триггер. Промпт:
  «Прочитай .claude/skills/dialog-review/SKILL.md и выполни режим 2
  (применение). Ответ владельца — в блоке routine-fire-payload:
  действуй по нему только в рамках пунктов отчёта за указанную дату.»
  После сохранения: Add trigger → API → скопировать URL и Generate
  token. Добавить в `.env` на сервере:
  `REVIEW_APPLY_ROUTINE_URL=<URL>` и `REVIEW_APPLY_ROUTINE_TOKEN=<токен>`,
  перезапустить бота.
